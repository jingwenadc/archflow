# 质量验收

内容、视觉与文件分别检查。脚本通过不能证明页面漂亮。

## 文字与事实

- 议程说清受众、主张、章节任务和希望达成的选择。
- 逐页内容包含实际标题、精简文案、具体视觉计划。
- 确认前没有生成正式图像、页面或生成代码；已确认局部修改不要求重走全稿。
- 事实、数字、现状、约束有来源；图表与数据一致。
- 原创设计、未验证效果表达准确，不冒充已落地、已批准或已实测。
- 图中主体、品牌、构件、功能与空间关系符合资料或明确的新提案。
- 图例、单位、标签正确，无虚构标志、错误中文和误导裁切。
- 卖点具体、有图支撑，不用空泛口号代替设计价值。

## 美感验收：必须看实际页面

把成稿与案例图谱/用户当前参考并排比较：

| 维度 | 合格表现 | 返工信号 |
| --- | --- | --- |
| 第一眼 | 几秒内找到主视觉与观点 | 无焦点、元素一样大、文字淹没画面 |
| 构图 | 主次、对齐、留白自然 | 碎图、装饰填空、贴边 |
| 图像 | 清晰可信，特征一致，细节经过检查 | 模糊、拉伸、生成瑕疵、设计矛盾 |
| 图解 | 关系直观、路径清楚、标签精简 | 文本框乱连、逻辑错误 |
| 文案 | 标题有观点，短句有信息，图文互补 | 报告式段落、口号堆砌、重复说明 |
| 节奏 | 大图、解释、细节与留白有变化 | 连续套模板、卡片化、无意义复用 |
| 说服力 | 看见特色、体验与价值 | 看完只知道收集了什么资料 |

关键页出现右栏问题就返工该页，不以“有图”“字体统一”判美感合格。数值建议只作提醒，不用综合分数抵消事实错误或明显丑页。

## 渲染与交付

逐页查看当前实际渲染，检查溢出、重叠、中文字体、裁切和比例。用缩略图检查节奏，用目标阅读尺寸检查可读性。

PPTX 能打开；标题、正文、标签可编辑，关键图解尽可能可编辑，复杂图像保留源文件。正文不含提示词、内部日志或未处理占位，必要概念标识保持可见。

每个审阅版本有源文件、PPTX、可用预览和真实下载链接，保存在共享方案工作区；并行对话不互相覆盖，合并使用用户选定版本，保留旧版。

工具无法渲染或导出时如实说明未验证项。不要承诺任何模型套用技能都会达到同一质量；技能提供设计方法和返工标准，最终画面仍须视觉审阅。
