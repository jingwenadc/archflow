## 案例 A：数智国能体验中心

- 共 79 页，自定义横向比例约 1.383:1。
- 内嵌文字使用 Arial、微软雅黑、幼圆、仿宋、宋体和华文细黑。
- 以白底为主，固定元素使用克制灰色，强调色来自能源品牌。
- 结构为：任务解读 → 项目定位 → 现状分析 → 功能与逐层布局 → 各空间平面及效果图 → 体验空间 → 结束。
- 值得迁移的做法：稀疏章节页、居中的问题转折页、从品牌元素提取概念与颜色、楼层爆炸轴测、淡化总平面加红色定位、平面与效果图配对、横向室内主图、灰模加材料批注。
- 不应照搬的问题：近似效果图重复、小号批注过多、部分页面信息不足，以及连续平面页缺少节奏重置。

## 案例 B：海南莫斯科动力大学

- 共 120 页，A3 横向比例约 1.414:1。
- 内嵌文字使用微软雅黑、Arial Bold、Arial Narrow 和 Bodoni MT Black。
- 形成两个协调系统：白底分析与图纸页，黑底概念与景观页。
- 结构为：前置方案预览 → 项目背景 → 规划方案 → 建筑设计 → 景观策略 → 效果图 → 技术附录 → 第二方案 → 方案比选 → 结束。
- 值得迁移的做法：图片条带章节页、轻量双语标签、概念方程与生成序列、总图叠加分析、单一信息层分析图、黑底分类图解、景观拼贴、平面与效果图配对、相同条件的方案比选。
- 不应照搬的问题：篇幅过长、技术正文过密且字号偏小、素材清晰度不一致、部分总图重复但没有新增结论，以及未与项目证据配对时容易被误读的效果图。

## 合并后的设计基因

- 安静边框、强层级、少装饰；
- 页面级双语标签，不做整段双语重复；
- 白底承载分析和证据，深色承载概念综合与体验；
- 每张分析页只放一个主图解或主图纸；
- 通过小型定位图维持跨页空间方向；
- 主视觉可以开场吸引兴趣，也可在概念推导后展示体验；位置取决于叙事目的；
- 用章节页和高留白转折页控制长篇节奏；
- 颜色用于表达概念、功能或路线，并在全稿保持稳定。
