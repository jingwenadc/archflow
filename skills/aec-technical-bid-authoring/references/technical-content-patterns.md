# 技术内容模式

只读取与当前标的类型相关的部分。招标规定目录优先于以下建议结构。

## 共同骨架

每个评分章节使用“项目条件 → 风险/目标 → 措施 → 组织/资源 → 时间 → 检查/验收 → 异常处置 → 记录成果”的闭环。开头一段直接响应评分因素，结尾用一张短表汇总关键控制点、责任角色和证据成果。

## 设计服务技术响应

适合建筑、室内、修缮、机电、景观及全过程设计服务：

- 设计范围和界面：逐条覆盖采购需求，明确包含、不包含与协作边界。
- 现状核查：资料复核、现场踏勘、检测/测绘需求、问题台账和待确认条件。
- 重点难点：区分跨项目共性与子项个性，每个难点必须接解决路线和验证成果。
- 技术方案：按建筑/结构/给排水/暖通/电气/造价/BIM等专业组织，说明接口与成果深度。
- 质量：校审层级、清单、碰撞检查、审查意见闭环、变更与版本管理。
- 进度：阶段、依赖、评审点、交付物、缓冲和变更重排，不虚构可审批时长。
- 服务：汇报、报审配合、招标配合、交底、现场服务、变更、验收和归档。
- 保密：分级、访问权限、传输、存储、外发、离场和销毁；若标题承诺保密，正文必须实际覆盖。

技术参数只有在采购需求、可靠调查或已完成计算支持时才能写成确定值。踏勘前可写“计算/检测后确定”的方法和判定流程，不能填入看似精确的厚度、面积或性能等级。

## 施工组织设计

适合房建、改造、保护修缮和机电施工：

- 施工部署与技术措施：流水段、工序、临设、交通、接口、样板/首件和验收。
- 质量体系：目标分解、材料复验、隐蔽验收、旁站、实测实量、资料同步和缺陷闭环。
- 安全与绿色施工：危大工程识别、许可、监测、消防、临电、高处作业、扬尘噪声和废弃物。
- 进度：关键线路、里程碑、资源曲线、前置审批、供应链、纠偏阈值和赶工边界。
- 劳动力与机械：按阶段配置，写明来源、进退场、备用能力和设备适用性。
- 重点难点：来源于现场、图纸、清单和使用限制，不采用所有项目都适用的空泛清单。
- 成品/既有工程保护：对象分级、交接、覆盖/隔离/监测、损坏响应和责任记录。
- 应急与季节施工：风险触发、指挥、停复工条件、物资、疏散、报告和恢复。

## 文物保护修缮

除施工共同骨架外，重点建立：价值要素/原构件识别、最小干预、原材料/原工艺优先、可逆性、试验段、现状记录、构件编号、拆解与复位台账、样品封存、全过程影像、文物主管部门/监理/设计签认节点和意外发现处置。不得将普通翻新逻辑替代保护修缮原则。

## 医疗、校园或不停用场景

明确运营边界、洁污/师生与施工流线、分区封闭、噪声振动时窗、停水停电计划、感染/粉尘控制、应急通道、材料运输和每日恢复。涉及具体医院、学校运行条件时必须有项目来源，不能从场景类型推断事实。

## 图表选择

优先采用：评分到章节导航表、技术路线图、项目组织图、RACI责任表、里程碑/网络计划、阶段资源表、质量控制点表、风险登记册、检查与交付清单、总平面组织示意和节点工艺图。没有可靠数据时不要生成资源曲线或比例化甘特图。
